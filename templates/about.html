Signature Forgery Detection System

About the Project

The Signature Forgery Detection System is a deep learning–based web application developed to verify handwritten signatures and identify whether a given signature is Genuine or Forged.

🎯 Project Objective

  • To automate handwritten signature verification
  • To reduce human error in manual signature checking
  • To provide a secure and reliable verification system
  • To maintain user test history for tracking and analysis

⚙️ How the System Works

  1. User logs in using email and password
  2. User uploads a signature image
  3. The image is preprocessed using OpenCV
  4. A trained CNN model analyzes the signature
  5. The system predicts whether the signature is Genuine or Forged
  6. The result and accuracy are displayed
  7. Test details are saved for future reference

🧠 Technology Used

  • Frontend: HTML, CSS
  • Backend: Python (Flask)
  • Database: SQLite
  • Deep Learning: CNN (TensorFlow & Keras)
  • Image Processing: OpenCV

👤 User Module

  • User Registration & Login
  • Upload and test signatures
  • View result and accuracy
  • View test history
  • Secure logout

🛡️ Admin Module

  • Admin login with fixed credentials
  • View registered users
  • View all signature test history
  • Monitor user activities

📈 Advantages

  • Fast and accurate verification
  • Reduces manual effort
  • User-friendly interface
  • Secure data storage

🔮 Future Enhancements

  • Improve model accuracy with larger datasets
  • Support real-time signature capture
  • Cloud deployment
  • Mobile application integration

Conclusion: This project demonstrates how deep learning can be effectively used to solve real-world security problems by automating signature verification in a secure and reliable manner.
