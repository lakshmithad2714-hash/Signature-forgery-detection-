# Signature Forgery Detection using Deep Learning

## Overview
This project is a Deep Learning–based Signature Forgery Detection System developed to identify whether a signature is genuine or forged. The system uses image processing and Convolutional Neural Network (CNN) techniques to analyze signature patterns and perform accurate classification.

The project is implemented using Python along with Deep Learning and Computer Vision libraries such as TensorFlow, Keras, and OpenCV.

---

## Features
- Genuine vs Forged Signature Detection
- Image Preprocessing and Enhancement
- Deep Learning Model Training using CNN
- Signature Classification and Prediction
- User-Friendly Interface
- Real-Time Signature Verification
